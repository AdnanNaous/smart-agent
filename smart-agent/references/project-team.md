# Adaptive project collaboration

## Decide whether collaboration adds value

Use native subagents for independent work, specialist context, context isolation, useful parallelism, or difficult independent verification when permitted. Stay with the current agent for small or cohesive tasks where handoffs add overhead. Roles are temporary responsibilities, not a mandatory researcher/designer/builder/reviewer pipeline or fixed model mapping.

Track only assignments that matter: owner, artifact, dependency, acceptance criteria, status, and actual route when relevant. Keep planned assignments distinct from running workers. Use the existing plan rather than redundant project-management files.

## Brief and coordinate

Provide the goal, user constraints, relevant raw artifacts or exact paths, project instructions, source references, acceptance criteria, write ownership, and required evidence. Use minimal context for independent judgment; inherit history when useful. Match model/effort overrides and history forks to live controls and user preferences; no explicit pair is required for every unit.

Assign disjoint files to concurrent writers or designate an integration owner. Keep nested delegation coordinator-controlled unless a bounded need justifies it. Ask for findings, tradeoffs, checks, and blockers rather than private reasoning. Do not simulate agents or conversations.

Run independent work in parallel and dependencies in sequence. Reuse a suitable worker when its context remains useful. Change routing only through supported controls. Respect actual concurrency and resource limits. Share consequential findings with workers who need them instead of duplicating whole contexts.

## Integrate and verify

Resolve disagreements with a source, reproduction, or discriminating check rather than repeated debate or vote counts. Review actual requirements and artifacts instead of repeating implementation merely to obtain agreement.

Wait for required results, reconcile edits, inspect the combined diff, and verify integrated behavior. Recover stalled dependencies from actual state; do not restart verified work because its reasoning is unavailable. The coordinator remains accountable for final integration and verification.

Workers should inspect their own capabilities rather than assuming the coordinator's access carries over. Preserve the user's authorized scope across handoffs. Finish independent useful work when one dependency is blocked. Report meaningful outcomes and limitations without agent theater or invented savings.
